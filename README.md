# Thread

Thread is a polished notes app built with HTML, CSS, and vanilla JavaScript. It stores notes locally using `localStorage`, supports tags, manual note connections, and a lightweight knowledge graph.

## Features

- Create, edit, and delete notes
- Add tags and manage note metadata
- Search notes by title, content, or tags
- Sort notes by last modified, creation date, and title
- Connect notes manually and see linked notes in the editor
- Visual knowledge graph of notes and connections
- AI Insights placeholder section for future intelligence
- Responsive layout and light/dark theme support

## Project structure

- `index.html` — app shell and UI structure
- `style.css` — responsive modern styling
- `script.js` — app initialization and main UI logic
- `ui.js` — rendering, event handling, and UI state
- `data.js` — note creation, updates, connections, and persistence logic
- `graph.js` — lightweight SVG knowledge graph rendering
- `storage.js` — localStorage helpers
- `assets/` — reserved for future icons or illustrations

## Deployment

This project is ready for GitHub Pages. Serve the app from the repository root and ensure the site is loaded over HTTP/HTTPS.

## Usage

Open `index.html` in a browser, or deploy with GitHub Pages. Notes are saved locally to your browser and remain private to the device.
